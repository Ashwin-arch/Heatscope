# HeatScope — Reproduction Guide

This directory contains the paper and every artifact used to verify its claims.

| File | Purpose |
| --- | --- |
| `paper.md` | Authoritative paper source (Markdown). |
| `HeatScope_IEEE_Research_Paper.tex` | Assembled IEEEtran LaTeX generated by `build_pdf.py`. |
| `HeatScope_IEEE_Research_Paper.pdf` | Camera-ready IEEE-formatted PDF (10 pages). |
| `HeatScope_IEEE_Research_Paper.docx` | Editable DOCX edition for review. |
| `BIBLIOGRAPHY.md` | Every reference with verification status, source URL, and notes. |
| `CLAIM_VERIFICATION_MATRIX.md` | Claim-by-claim verdicts with artifact paths. |
| `MISSING_EVIDENCE.md` | Evidence gaps and the framing decisions taken for each. |
| `make_figures.py` | Regenerates all six figures from `../results/`. |
| `figures/` | Publication figures embedded in the paper. |
| `build_pdf.py` | Markdown → IEEEtran LaTeX → PDF. |
| `build_docx.py` | Markdown → DOCX. |

## Rebuilding the paper

```bash
cd paper
python make_figures.py      # writes figures/fig1..fig6 (needs ../results/)
python build_pdf.py         # writes HeatScope_IEEE_Research_Paper.{tex,pdf}
python build_docx.py        # writes HeatScope_IEEE_Research_Paper.docx
```

Toolchain used for the committed PDF and DOCX: Pandoc 3.10.2, pdfTeX 3.141592653 with
`IEEEtran.cls` from TeX Live, LibreOffice 7.x for the DOCX round-trip check.

`build_pdf.py` post-processes Pandoc's LaTeX output because Pandoc emits `longtable`
(illegal in a two-column IEEE layout) and renders Markdown image captions as
description lists. The script converts both into IEEEtran `table`/`table*` and
`figure` floats, moves the abstract and index terms into IEEEtran macros, and
rebuilds the hand-numbered reference list as a `thebibliography`. It aborts if any
unconverted markup remains.

## Canonical pipeline order

Each stage reads `data/processed/` and writes `results/`. Run from the repository
root with `.venv/bin/python heatscope/<module>.py`.

```bash
python heatscope/satellite.py                 # Landsat 8 STAC search → data/raw/scene_metadata.csv
python heatscope/preprocess.py                # Landsat scaling, QA mask → data/processed/*.tif
python heatscope/grid.py                      # 250 m EPSG:32643 cells → results/heatscope_grid.gpkg
python heatscope/population.py                # WorldPop aggregation
python heatscope/buildings.py                 # Overture building counts/area/coverage
python heatscope/landsat_features.py          # within-cell p95 LST and spectral means
python heatscope/merge_landsat.py             # joins Landsat features to the grid
python heatscope/merge_features.py            # final analysis table
python heatscope/build_hvi.py                 # heat vulnerability index
python heatscope/weather.py                   # NASA POWER retrieval (not used by any model)
python heatscope/integrate_weather.py         # weather join (constant columns; excluded)
python heatscope/create_spatial_blocks.py     # 240 contiguous ~2.5 km CV blocks
python heatscope/feature_audit.py             # audit/NDMI redundancy
python heatscope/spatial_ml_benchmark.py      # base five-feature benchmark
python heatscope/reduced_spatial_ml.py        # reduced-feature benchmark
python heatscope/context_spatial_benchmark.py # 9-feature context benchmark
python heatscope/context_shap.py              # TreeSHAP + additivity diagnostics
python heatscope/spatial_uncertainty.py       # cross-fitted prediction intervals (primary)
python heatscope/adaptive_uncertainty.py      # exploratory adaptive intervals
python heatscope/operational_priority.py      # operational priority index
python heatscope/operational_intervention_benefits_v2.py  # v2 benefit/cost scenario table
python heatscope/intervention_eligibility.py  # eligibility masks
python heatscope/budget_equity_frontier.py    # binding-budget equity sweep
python heatscope/capacity_optimizer.py        # secondary capacity-saturation MILP
python heatscope/operational_optimizer.py     # primary equity-floor MILP
python heatscope/intervention_sensitivity.py  # 500-run Monte Carlo
python heatscope/final_benchmark.py           # consolidated comparison table
```

Scripts named `*_before_*`, `*_pre_*`, `demo*`, `google_map*`, `optimization_*`,
`optimization_v2.py`, `intervention_baseline.py`, `intervention_scores.py`,
`operational_intervention_benefits.py`, `shap_analysis.py`, `shap_dependence_analysis.py`,
`reduced_shap.py`, `spatial_context.py`, `spatial_error_analysis.py`,
`tail_uncertainty_refinement.py`, `pareto_analysis.py`, and `capacity_frontier.py`
are exploratory, superseded, or demo-only and do not produce reported results.
Despite its name, `operational_intervention_benefits_v2.py` is the canonical
benefit script for every number in the paper.

## Verification targets

Re-running the reported stages reproduced the saved artifacts. Base benchmark
metrics agreed to ≈4.44e-16; context metrics reproduced exactly; and
`results/context_shap_feature_importance.csv` was byte-identical to the committed
original.

Base five-feature benchmark (mean ± SD over five block-grouped folds):

| Model | MAE (°C) | RMSE (°C) | R² |
| --- | --- | --- | --- |
| HistGradientBoosting | 1.2126 ± 0.0512 | 1.5909 ± 0.0701 | 0.6356 ± 0.0426 |
| XGBoost | 1.2150 ± 0.0470 | 1.5953 ± 0.0686 | 0.6336 ± 0.0424 |
| Random Forest | 1.2178 ± 0.0511 | 1.5955 ± 0.0744 | 0.6334 ± 0.0447 |
| Extra Trees | 1.2262 ± 0.0540 | 1.6074 ± 0.0761 | 0.6280 ± 0.0458 |
| Linear Regression | 1.2901 ± 0.0684 | 1.6983 ± 0.0885 | 0.5846 ± 0.0535 |

Feature ablation: reduced 5-feature MAE 1.2241 / RMSE 1.6060 / R² 0.6286 versus
context 9-feature MAE 1.1738 / RMSE 1.5478 / R² 0.6548 (−4.11% MAE, −3.62% RMSE,
+0.0262 R²). Hottest-quintile bias falls from +1.5005 °C to +1.3792 °C.

Attribution: neighbourhood-context subtotal 45.42% of total TreeSHAP magnitude;
focal plus neighbourhood NDMI 49.38%. TreeSHAP additivity residuals: mean absolute
error 4.59e-4 °C, median 1.51e-8 °C, maximum 1.09 °C — a consequence of
interventional TreeSHAP with a 100-row background sample.

Cross-fitted prediction intervals: overall coverage 94.94%, mean width 6.14 °C;
quintile coverage 93.54%, 97.78%, 98.07%, 97.46%, 87.85% from Q1 to Q5.

Allocation: budget-bound operational MILP benefit 2470.69 unconstrained, 2341.74
at α = 0.6 (−5.22%), 2007.31 at α = 0.7 (−18.76%). Secondary capacity-saturation
result: greedy 1616.44, MILP 2074.49 (+28.34%). Sensitivity: 475 of 500 runs
certified optimal by HiGHS; 25 time-limited runs are stored as missing.

## Known reproducibility failures

1. `heatscope/satellite.py` searches a rolling 180-day window and selects the
   lowest-cloud scene, so re-running acquisition can select a different scene than
   the pinned `scene_metadata.csv`. The paper reports the pinned artifact, not a
   re-acquisition guarantee.
2. Without `data/raw/` and `data/processed/` there is no clean-room rerun.
3. No WorldPop release identifier, licence text, or checksum is recorded, and no
   downloader or checksum manifest exists for the building tile.
4. `intervention_sensitivity.py` leaves 25 of 500 runs unsolved within the time
   limit; the artifact encodes them as missing rather than reporting a bound.
5. Hardware, wall-clock runtime, and peak memory were never instrumented.
6. No formal coverage guarantee is claimed for the intervals; they are empirically
   calibrated on the reported folds only.
